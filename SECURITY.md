# Security policy — repo-factory

## Supported versions

| Version | Supported |
| --- | --- |
| 1.0.x | ✅ |

## Reporting a vulnerability

Email or privately report via GitHub Security Advisories on `https://github.com/theworker02/repo-factory` when available.

Please include:

- Impact assessment
- Reproduction steps
- Affected versions
- Any suggested fix

We aim to acknowledge reports within a reasonable window and to coordinate disclosure.

## Non-goals

`repo-factory` performs local computation only. It should not request network credentials. If you observe unexpected network behavior, treat it as high priority.
